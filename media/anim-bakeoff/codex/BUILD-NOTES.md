# Animation approach

- **Cold open:** A fast accent rule and kicker set the beat. Four masked title lines arrive with a tight stagger and soft blur that resolves quickly. The date and live indicator settle after the title; the final frame holds from about 9.2 seconds.
- **URK pipeline:** The four cards appear in travel order as a teal pulse crosses the live link. A second amber pulse follows an Unreal edit, and the simulator scene changes with it. The headset card is labeled as a packaged app, while the simulator is the explicit live preview surface. The final diagram holds after about 9.3 seconds.
- **Classes reveal:** Rows arrive every 0.74 seconds so all six appear in under six seconds. An amber bracket binds the two Creative AI parts, then the class URL enters. The complete schedule holds after about 7.9 seconds.

All slides use fixed 1920 × 1080 stages scaled to the viewport, inline CSS and JavaScript, system fonts, and `window.__restart()` for replay.
